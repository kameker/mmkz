# Гауссовы фильтры и морфология в OpenCV (Python)

В `lab_filters.py` выполнены упражнения 1–5 и продолжение 8–9. Устаревшему вызову
`cv::smooth(..., CV_GAUSSIAN, ...)` в современном Python соответствует
`cv2.GaussianBlur(...)`.

## Запуск

```powershell
python -m pip install -r requirements.txt
python lab_filters.py --show
```

Без аргументов используются автоматически созданные демонстрационные сцены.
Чтобы выполнить работу на своих фотографиях:

```powershell
python lab_filters.py `
  --texture images/texture.jpg `
  --threshold 25 --show
```

Для упражнения 4 используются фиксированные файлы из папки проекта:

- `i3.jpg` — первый снимок сцены;
- `i4.jpg` — второй снимок той же сцены.

Для упражнения 5 используются два файла из папки проекта с фиксированными
именами:

- `i1.jpg` — первый снимок сцены без чашки;
- `i2.jpg` — второй снимок той же сцены с чашкой.

После размещения файлов достаточно выполнить `python lab_filters.py --show`.

Все изображения должны иметь одинаковый размер внутри соответствующей пары.
Результаты также сохраняются в каталог `results/`. Если маска чашки содержит
много шума, увеличьте `--threshold`; если части чашки исчезают — уменьшите.

## Краткие ответы

1. Два размытия 5x5 и одно 11x11 похожи, но не совпадают. При последовательной
   свертке дисперсии гауссиан складываются (`sigma_total² = sigma1² + sigma2²`),
   а эффективное ядро двух фильтров 5x5 имеет размер 9x9. Автоматически выбранная
   OpenCV сигма для 11x11 другая, также влияют дискретизация и границы. Исходная
   абсолютная разность выглядит почти черной, потому что ее значения малы по
   сравнению с полной шкалой 0–255. Поэтому рядом выводится нормализованный
   вариант с усиленным контрастом; он предназначен только для визуализации.

2. Единичный яркий пиксель после размытия становится изображением самого
   двумерного гауссова ядра. Два фильтра 5x5 дают эффективное ядро 9x9 и результат,
   похожий на 9x9, но не идентичный из-за различающихся сигм и коэффициентов.

3. При фиксированном ядре 9x9 большая сигма обрезается границами ядра, поэтому
   результаты отличаются от режима `(0, 0)`, где OpenCV подбирает достаточно
   большое ядро по сигме. `sigmaX=1, sigmaY=9` сильно размывает по вертикали,
   обратная пара — по горизонтали. Последовательность этих двух фильтров почти
   не зависит от порядка и дает большую итоговую сигму по обеим осям
   (`sqrt(1²+9²)`). Это не то же самое, что небольшой фильтр 9x9 с auto-sigma.

4. В формулировке `src1 минус src1` опечатка: используется `src1 минус src2`.
   Разность не черная из-за шума матрицы, автоэкспозиции, баланса белого,
   сжатия и микросдвига камеры. Эрозия с последующей дилатацией (opening) удаляет
   мелкие светлые точки, а дилатация с последующей эрозией (closing) заполняет
   мелкие темные разрывы — поэтому результаты различны.

5. Контур строится как `mask XOR erode(mask)`: эрозия удаляет внешний слой
   объекта, а XOR оставляет именно этот удаленный граничный слой.

8–9. Маска обходится от левого верхнего угла по строкам. При встрече пикселя
   255 его 8-связная компонента временно заливается значением 128 с помощью
   `cv2.floodFill()`. Ее площадь сравнивается с площадью крупнейшей найденной
   компоненты; меньшая область заливается нулем. В конце единственная оставшаяся
   область снова получает значение 255. Результаты сохраняются как
   `exercise_8_9.png` и `cup_largest_component.png`.
